# Release provenance

The public snapshot is based on local Chladni V3 commit `310e9bd4539082a8f31db0ca4bdd74ea4926015f`, branch `forschung-v3`. Its V2 baseline is `9c202ed85e6b9a530fb8e65d806c84805cb56117`. Those commits belong to the local research history. This repository starts with a new root commit.

The export includes original source, numeric model settings, tests, methodological documentation and an initial solver-generated title image. The public snapshot adds a raw-data-free command to rerun the numerical and synthetic figure pipelines, documents private input requirements, and records licensing. The original experiment files, private analysis outputs, per-image reference and registration tables, archive inventories, historical study outputs, caches and local Python environments are excluded.

The numerical and image-processing findings are those of the local research record. The seven experimental control images remain unassigned by the fixed rule. The published synthetic examples use independent seeded mode fields under the modeled families. No independent human reference annotations are available.

See the [reproduction guide](dokumentation/V3_REPRODUKTION.md), [research results](dokumentation/V3_ERGEBNISSE.md) and [licensing overview](LICENSING.md).

The README was later updated with two approved experimental image panels at 4,122 Hz and 3,723 Hz. Their source frames and derived views are described in the [figure provenance](dokumentation/V3_REPRODUKTION.md#bildtafeln-aus-zwei-freigegebenen-aufnahmen). The archive originals remain private.
